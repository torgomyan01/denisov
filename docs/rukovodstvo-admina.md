# Руководство администратора сайта кафе «Денисов»

Документ для сотрудников, которые ведут сайт, меню и заказы.  
Адрес панели: **https://cafedenisov.ru/admin**  
(локально: `http://localhost:3000/admin`)

Полная актуальная справка также в админке → **Инструкции** (поиск по разделам).

---

## 1. Вход и сохранение

1. Откройте `/admin`, введите пароль администратора.
2. **Hero / О кафе / Контакты** — правки на экране; на сайте появятся после **«Сохранить»** (Ctrl/Cmd+S).
3. **Меню (iiko)**, доставка (зоны), самовывоз, заказы, пользователи — сохраняются своими кнопками внутри раздела.

У пункта **«Заказы»** есть счётчик новых (статус «Не подтверждён»).

---

## 2. Структура панели

| Раздел | Для чего |
|--------|----------|
| Hero / О кафе / Контакты | Контент главной |
| Каталог → Меню | Меню из **iiko**: видимость, наличие, фото, тексты поверх |
| Доставка | Зоны на карте, цена по зоне, приём заказов |
| Самовывоз | Точки выдачи |
| Заказы | Заказы **с сайта**: карточка, этикетка, повтор в iiko, удаление (×) |

| Аналитика | Выручка, клиенты, топ блюд, статусы и график по дням |
| Пользователи | Клиенты и курьеры |
| Инструкции | Эта справка в панели |

## 3. Меню

Источник меню — **iiko Cloud**. В админке не создают блюда с нуля.

- Категория / позиция: «Показывать на сайте», «В наличии», фото и оверрайды текста.
- Порядок категорий — перетаскиванием.
- Цена и обязательные модификаторы — из iiko; гость выбирает их при добавлении в корзину.

---

## 4. Доставка (зоны)

Раздел **«Доставка»** — районы на Яндекс.Карте и цена за зону.

1. **Новая зона** → кликами обведите район (минимум 3 точки) → **Готово** (или двойной клик).
2. Укажите название, цвет, стоимость доставки, при необходимости «бесплатно от» и мин. сумму.
3. **Зона активна** → **Создать зону**.
4. Несколько зон можно; при пересечении берётся зона выше в списке.
5. Гость ставит точку **только внутри** зоны; иначе ошибка «доставки нет». Цена в корзине — из этой зоны.
6. **Общие настройки** сверху: приём заказов вкл/выкл и запасные цены, если зон ещё нет. После правок — **Сохранить настройки**.

### Оплата при оформлении

- **При получении** — оплата курьеру / в точке; на сайте статус «ожидает оплаты».
- **Онлайн картой** — пока тестовый режим (списания нет); заказ помечается оплаченным.

В карточке заказа в админке видны способ и статус оплаты; в iiko уходит пометка в комментарии (и payments — только если оплачено онлайн и настроен paymentTypeId).

## 5. Заказы и iiko

1. Гость оформляет заказ → запись на сайте **и** создание доставки в iiko.
2. **Статус на сайте только из iiko.** Вручную в админке статус не меняется.
3. Откройте / обновите список или карточку — подтянутся статусы открытых заказов.
4. Ошибка создания в iiko → в карточке текст ошибки и **«Отправить в iiko снова»**.
5. Удаление: **×** на карточке в списке «Заказы» — только с сайта; в iiko заказ не отменяется.
6. Все доставки за день (любой канал) — раздел **«Заказы iiko»**.

### Статусы (iiko → гость)

| iiko | У гостя (кратко) |
|------|------------------|
| Unconfirmed | Получен |
| WaitCooking / ReadyForCooking | Подтверждён |
| CookingStarted | Готовим |
| CookingCompleted | Готов |
| Waiting | К выдаче / К доставке |
| OnWay | В пути |
| Delivered | Доставлен |
| Closed | Завершён |
| Cancelled | Отменён |

Ведите этапы в iiko (или на станции). Сайт и личный кабинет обновятся сами. Push — если клиент включил уведомления в профиле.

---

## 6. Распорядок смены

1. В «Меню» снять с продажи то, чего нет.
2. Проверить зоны доставки и приём заказов.
3. Следить за «Заказы» и счётчиком.
4. Статусы — в iiko.
5. При необходимости — «Заказы iiko» за день.

## 7. FAQ

| Вопрос | Ответ |
|--------|--------|
| Hero не обновился | Нужна «Сохранить» + Ctrl+F5 |
| Нет блюда на сайте | Есть в iiko? Включено «Показывать на сайте»? |
| «Закончилось» | Выкл. «В наличии» |
| Гость не выбирает адрес | Точка вне зон → проверьте «Доставка» |
| Не та цена доставки | Цена из зоны точки; смотрите пересечения |
| Нельзя сменить статус | Только из iiko → «Обновить из iiko» |
| Ошибка iiko у заказа | Карточка → повторная отправка |
| Удалить старый заказ сайта | × в списке «Заказы» |
