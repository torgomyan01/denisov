# Руководство администратора сайта кафе «Денисов»

Документ для сотрудников, которые ведут сайт, меню и заказы.  
Адрес панели: **https://cafedenisov.ru/admin**  
(локально: `http://localhost:3000/admin`)

Полная актуальная справка также в админке → **Инструкции** (поиск по разделам).

---

## 1. Вход и сохранение

1. Откройте `/admin`, введите пароль администратора.
2. **Hero / О кафе / Контакты** — правки на экране; на сайте появятся после **«Сохранить»** (Ctrl/Cmd+S).
3. **Меню (iiko)**, доставка (зоны), самовывоз, заказы, пользователи — сохраняются своими кнопками внутри раздела.

У пункта **«Заказы»** есть счётчик новых (статус «Не подтверждён»).

## 3. Меню

Источник меню — **iiko Cloud**. В админке не создают блюда с нуля.

- **Автообновление:** сервер сам синхронизирует меню с iiko **каждые 10 минут**. Изменения цен и состава появляются на сайте в течение этого времени.
- **Важно про новые позиции:** на сайт попадает только то, что есть во **внешнем меню «Сайт»** (ID 97443) в iikoWeb, в той же ценовой категории «Базовая категория». Позиция, которая есть в iiko, но не добавлена во внешнее меню «Сайт», на сайте **не появится**. Чтобы добавить новое блюдо, добавьте его в iikoWeb → Внешние меню → «Сайт», затем подождите до 10 минут или нажмите «Обновить из iiko».
- **Обновление вручную:** если нужно применить правки из iiko прямо сейчас — нажмите **«Обновить из iiko»** в шапке раздела «Меню».
- Категория / позиция: «Показывать на сайте», «В наличии», фото и оверрайды текста/цены. Пустые поля оверрайдов всегда берутся из iiko; чтобы вернуть значения из iiko, в карточке блюда есть кнопка **«Сбросить тексты и цену к iiko»**.
- Порядок категорий — перетаскиванием.
- Цена и обязательные модификаторы — из iiko; гость выбирает их при добавлении в корзину.

## 4. Доставка (зоны)

Раздел **«Доставка»** — районы на Яндекс.Карте и цена за зону.

1. **Новая зона** → кликами обведите район (минимум 3 точки) → **Готово** (или двойной клик).
2. Укажите название, цвет, стоимость доставки, при необходимости «бесплатно от» и мин. сумму.
3. **Зона активна** → **Создать зону**.
4. Несколько зон можно; при пересечении берётся зона выше в списке.
5. Гость ставит точку **только внутри** зоны; иначе ошибка «доставки нет». Цена в корзине — из этой зоны.
### Кнопка «Настройки» (общее окно)

В шапке раздела **Доставка** справа есть кнопка **«Настройки»**. Она открывает окно **«Общие настройки»**:

- **Приём заказов** — вкл/выкл корзину на сайте.
- **Оплата курьеру при доставке** — разрешить или запретить оплату наличными/картой курьеру.
- **Цены без зон** — мин. сумма, цена доставки, «бесплатно от» (если зон ещё нет или как запасной тариф).

**Сохранить** — применить изменения. **Отмена** или крестик — закрыть без сохранения. Общая кнопка «Сохранить» Hero/контактов для этого не нужна.

### Оплата при оформлении

Сейчас курьеры внешней службы — по умолчанию **доставка только с онлайн-оплатой**. Самовывоз можно оплатить на кассе.

- **Доставка (по умолчанию)** — только **онлайн (Sber / SberPay)**.
- **Самовывоз · при получении** — наличными или картой **на кассе в кафе**; на сайте статус «ожидает оплаты»; заказ сразу уходит в iiko.
- **Онлайн (Sber / SberPay)** — гость платит на странице Сбера; заказ **сразу** уходит в iiko (ещё до оплаты); статус оплаты на сайте обновится после Sber.

#### Как снова включить оплату курьеру

Когда курьеры смогут принимать наличные или карту:

1. Админка → **Доставка**.
2. Справа в шапке нажмите **«Настройки»** — откроется окно.
3. Включите **«Оплата курьеру при доставке»**.
4. Нажмите **Сохранить**.
5. В корзине при доставке снова появится «При получении».

Выключить обратно — тем же переключателем в том же окне. Та же инструкция есть в админке → **Инструкция** → «Доставка» → «Оплата при оформлении».

В карточке заказа в админке видны способ и статус оплаты. В iiko: онлайн до оплаты — комментарий «Оплата: онлайн (ожидает)»; после Sber — `add_payments` + комментарий «Оплата: онлайн» (нужен `IIKO_PAYMENT_TYPE_ID`). Оплата при получении — «Оплата: при получении».

#### Если онлайн-оплата не прошла

Гостю **не нужно** оформлять заказ заново.

1. В **личном кабинете** (карточка заказа) или на странице **«Результат оплаты»** есть кнопка **«Оплатить снова»**.
2. Сайт создаёт **новую ссылку Sber** на **тот же** заказ.
3. В комментарии iiko: «Оплата: онлайн не прошла — ожидает повторной оплаты» (или «ожидает»).
4. После успешной оплаты на сайте статус **«Оплачен»**; в iiko — «Оплата: онлайн» + внешняя оплата.

## 5. Заказы и iiko

1. Гость оформляет заказ → запись на сайте **и сразу** создание доставки в iiko (любой способ оплаты).
2. **Статус на сайте только из iiko.** Вручную в админке статус не меняется.
3. Откройте / обновите список или карточку — подтянутся статусы открытых заказов (также фоново, пока открыт сайт).
4. При временных ошибках iiko (например *Creation timeout*) сайт **сам** повторяет отправку: сразу при оформлении (ожидание + повтор) и фоном при синхронизации (до 3 автоповторов). В истории заказа появятся записи «iiko автоповтор #…».
5. Если автоповторы не помогли — в карточке текст ошибки и **«Отправить в iiko снова»**. Убедитесь, что iiko Front / терминал онлайн.
6. Удаление: **×** на карточке в списке «Заказы» — только с сайта; в iiko заказ не отменяется. Оплаченный онлайн нельзя удалить, пока не сделан возврат на карту.
7. Все доставки за день (любой канал) — раздел **«Заказы iiko»**.

### Отмена заказа и возврат денег (важно)

Это **две разные** операции:

| Действие | Где | Что делает |
|----------|-----|------------|
| Отмена / закрытие заказа на кухне | **iiko** | Статус «Отменён» на сайте подтянется сам. **Деньги не возвращает.** |
| Возврат оплаты на карту | **Админка сайта** | Полный возврат через Sber (`refund` / `reverse`). **Заказ в iiko сам не отменяет.** |
| Удаление записи с сайта | **×** в списке «Заказы» | Только чистка списка на сайте. Не iiko и не Sber. |

**Как вернуть деньги гостю (онлайн Sber):**

1. Админка → **Заказы** → откройте карточку заказа.
2. В блоке **Оплата** должно быть: способ «Онлайн (Sber)», статус «Оплачен».
3. Нажмите **«Вернуть оплату на карту»** → подтвердите.
4. Дождитесь успеха: статус станет **«Возврат на карту»**.
5. Отдельно отмените заказ в **iiko** (если ещё не отменён).

**Ограничения:**

- Оплата «при получении» — кнопки возврата нет (на сайте деньги не списывались).
- Частичный возврат (не вся сумма) пока **не** поддерживается.
- Гость из личного кабинета сам вернуть/отменить оплату **не** может.
- Отмена только в iiko без кнопки в админке = кухня отменена, деньги остаются у ресторана, пока не нажмёте возврат на сайте.
- У API-учётки Sber должны быть права на возврат/отмену платежа.

### Статусы (iiko → гость)

| iiko | У гостя (кратко) |
|------|------------------|
| Unconfirmed | Получен |
| WaitCooking / ReadyForCooking | Подтверждён |
| CookingStarted | Готовим |
| CookingCompleted | Готов |
| Waiting | К выдаче / К доставке |
| OnWay | В пути |
| Delivered | Доставлен |
| Closed | Завершён |
| Cancelled | Отменён |

Ведите этапы в iiko (или на станции). Сайт и личный кабинет обновятся сами. Push — если клиент включил уведомления в профиле.

## 6. Распорядок смены

1. В «Меню» снять с продажи то, чего нет.
2. Проверить зоны доставки и приём заказов.
3. Следить за «Заказы» и счётчиком.
4. Статусы — в iiko.
5. При необходимости — «Заказы iiko» за день.
