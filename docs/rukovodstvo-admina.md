# Руководство администратора сайта кафе «Денисов»

Документ для сотрудников, которые ведут сайт, меню и заказы.  
Адрес панели: **https://cafedenisov.ru/admin**  
(локально при разработке: `http://localhost:3000/admin`)

---

## 1. Вход и общие правила

1. Откройте страницу `/admin`.
2. Введите **пароль администратора** (его выдаёт владелец / разработчик; хранится в настройках сервера).
3. После входа слева (на телефоне — сверху) видно меню разделов.

### Важно: кнопка «Сохранить»

Большинство правок сайта (**Hero**, **О кафе**, **Контакты**, **Меню**, **Доставка**) сначала меняются только на экране. Чтобы они появились на сайте для гостей, нажмите **«Сохранить»** в шапке панели.

- Горячая клавиша: **Ctrl + S** (на Mac — **Cmd + S**).
- Если уйти без сохранения, система спросит подтверждение.
- Разделы **Самовывоз**, **Заказы**, **Выдача по QR**, **Пользователи** сохраняются своими кнопками внутри раздела (отдельно от общей кнопки «Сохранить»).

### Значок новых заказов

Если появились новые заказы, у пункта **«Заказы»** показывается счётчик. Нажмите на него, чтобы открыть список.

## 3. Hero — первый экран главной

Здесь настраивается «лицо» сайта.

Что можно менять:

- **Верхняя строка** и **подзаголовок**
- **Адрес и часы** (короткая строка под текстом)
- **Логотип**: текст / картинка / скрыть
- **Featured-изображение** (большое фото) и подпись к нему
- **Бейдж** на фото (короткая метка)

Кнопки на hero зафиксированы системой (ведут в меню / контакты) — их состав не редактируется вручную.

После правок — **Сохранить**.

- **Часы работы** (и подпись)

## 6. Меню (каталог блюд)

Раздел **«Меню»** — основной для кухни и цен.

### Категории

1. **«+ Категория»** — создать раздел (Завтраки, Блюда, Напитки…).
2. Перетаскиванием можно **менять порядок** категорий и позиций.
3. У категории:
   - название;
   - **«Доступно с / до»** — окно времени для доставки (например, завтраки только до 12:00). Пусто = без ограничения.
4. Удаление категории удаляет и все блюда внутри — система спросит подтверждение.

### Позиция (блюдо)

Откройте блюдо (или **«+ Позиция»**), заполните:

| Поле | Смысл |
|------|--------|
| **Фото** | JPG / PNG / WebP. Лучше горизонтальное или квадратное, без лишнего фона |
| **Название** | Как на сайте и в заказе |
| **Описание** | Короткий текст для гостя |
| **Цена** | Число в рублях (можно «450» или «450 ₽») |
| **Вес / выход** | Например «250 г» |
| **Показывать в доставке** | Вкл. — блюдо можно заказать с доставкой / в корзине доставки |
| **В наличии** | Выкл. — на сайте «Закончилось», в корзину не кладут |
| **Допродажа** | Показывать в ленте «Добавить к заказу» |
| **Порядок в допродаже** | Чем меньше число, тем раньше в ленте |
| **КБЖУ на 100 г** | Ккал, белки, жиры, углеводы |

В списке блюд удобно искать по названию (поле поиска сверху).

После всех правок меню — обязательно **Сохранить**.

## 7. Доставка (правила и зона)

Вкладка **«Доставка»** — не список блюд, а **условия** доставки.  
Какие блюда участвуют в доставке — настраивается у каждой позиции в **«Меню»** (переключатель «Показывать в доставке»).

### Приём заказов

- **«Приём заказов включён»** — если выключить, гости **не смогут оформить заказ** (удобно при перегрузе кухни или техническом перерыве).

### Баннер

- Заголовок и подзаголовок
- Отдельные картинки для **десктопа** и **мобильного**

Рекомендуемые размеры (ориентир):

- десктоп ≈ 3200×1050  
- мобильный ≈ 880×800  

### Правила стоимости

| Параметр | Смысл |
|----------|--------|
| **Мин. сумма заказа** | Ниже этой суммы заказ не оформить (0 = без минимума) |
| **Стоимость доставки** | Фиксированная плата курьеру |
| **Бесплатно от** | При сумме корзины ≥ порога доставка 0 ₽ (0 = порог выключен) |

### Зона доставки

Два режима:

1. **Радиус от точки** — центр (широта / долгота) + радиус в км.  
2. **Полигон** — список координат `[[широта, долгота], …]` (минимум 3 точки). Обычно настраивает разработчик или менеджер с картой.

Адрес гостя проверяется по зоне: если точка вне зоны, доставка недоступна (остаётся самовывоз).

После правок — **Сохранить**.

## 8. Самовывоз

Точки, куда гость приезжает забрать заказ.

Для каждой точки:

- **Название** (как в корзине)
- **Телефон**
- **Адрес**
- **Точка на карте** (клик по карте)
- **Активна** — выключенную точку гости не увидят

Сохранение — кнопками **создать / сохранить** внутри этого раздела (общая кнопка «Сохранить» сайта здесь не нужна).

## 9. Заказы — ежедневная работа

### Список

1. Откройте **«Заказы»**.
2. При необходимости нажмите **«Обновить»**.
3. Фильтры:
   - поиск по **номеру**, **имени**, **телефону**, **названию блюда**;
   - фильтр по **статусу**.
4. Нажмите на заказ — откроется полная карточка.

### Карточка заказа

В карточке видно:

- номер заказа и текущий статус;
- клиент (имя, телефон, email);
- **самовывоз** (точка) или **доставка** (адрес, кв./подъезд/этаж/домофон, комментарий курьеру, кнопка «Открыть на карте»);
- время («как можно скорее» или ко времени);
- приборы и комментарий гостя;
- оплата и сумма;
- состав заказа с фото;
- блок **печати этикетки** (QR для выдачи).

### Статусы заказа

Менять статус можно только **по шагам** (кнопки следующих статусов в карточке).

| Статус | Значение |
|--------|----------|
| **Новый** | Только что оформлен |
| **Подтверждён** | Принят в работу |
| **Готовится** | Кухня готовит |
| **Готов** | Можно выдавать / отдавать курьеру |
| **В пути** | Только для доставки — курьер везёт |
| **Выдан** | Клиент получил заказ |
| **Отменён** | Заказ отменён |

Типовой путь:

**Самовывоз:**  
Новый → Подтверждён → Готовится → Готов → *(выдача по QR)* → Выдан  

**Доставка:**  
Новый → Подтверждён → Готовится → Готов → В пути → *(выдача по QR)* → Выдан  

Финальный статус **«Выдан»** для готового заказа обычно ставится через **сканирование QR** клиента (см. следующий раздел), а не вручную кнопкой «Выдан».

### Этикетка и QR

В карточке заказа можно:

- открыть превью этикетки;
- **распечатать** или **скачать** этикетку с QR-кодом выдачи.

Эту этикетку удобно клеить на упаковку. Клиент показывает свой QR в личном кабинете / в заказе — вы сканируете его в разделе выдачи.

## 10. Выдача по QR

Раздел **«Выдача по QR»** — для стойки и курьера.

1. Когда заказ в статусе **Готов** (самовывоз) или **Готов / В пути** (доставка), откройте этот раздел.
2. Разрешите камере доступ к камере браузера **или** введите код вручную.
3. Наведите камеру на QR клиента.
4. Проверьте состав и данные заказа на экране.
5. Подтвердите выдачу — статус станет **«Выдан»**.

Если камера недоступна (старый телефон / нет HTTPS), используйте ручной ввод кода с этикетки или из карточки заказа.

> Курьеры с ролью «курьер» также могут работать со сканером в своём личном кабинете (отдельная страница профиля).

## 11. Пользователи

Список клиентов, зарегистрированных на сайте.

Можно:

- **искать** по имени, телефону, email;
- **создать** пользователя вручную (имя, телефон, пароль);
- отметить **«Курьер»** — доступ к выдаче заказов;
- **редактировать** имя / телефон / пароль / роль;
- **удалить** учётную запись (с подтверждением).

Администратор сайта (пароль `/admin`) в этом списке не хранится как «клиент» — это отдельный вход.

## 12. Как работает сайт для гостя (кратко для понимания)

Чтобы админка была понятнее:

1. Гость смотрит меню на сайте и кладёт блюда **в корзину**.
2. Выбирает **самовывоз** (точку) или **доставку** (адрес + карта / подсказки адреса).
3. Указывает время, приборы, комментарий; при доставке — квартиру, подъезд и т.д.
4. Оформляет заказ → он появляется у вас в **«Заказы»** со статусом **Новый**.
5. Вы ведёте статусы на кухне → готовите → печатаете этикетку → выдаёте по QR.

Если **приём заказов выключен** в разделе «Доставка», оформить заказ нельзя.

Если блюдо **не в наличии** или **не в доставке**, гость его не закажет соответствующим способом.

---

## 13. Рекомендуемый распорядок дня

1. Утром проверить **«Приём заказов»** (включён).
2. Пройтись по меню: снять с продажи то, чего нет (**«В наличии»** выкл.), вернуть то, что появилось.
3. Держать вкладку **«Заказы»** открытой; реагировать на счётчик новых.
4. Новый заказ: **Подтвердить** → на кухню **Готовится** → **Готов**.
5. Самовывоз: выдача через **QR**. Доставка: после **Готов** — **В пути**, затем QR у двери.
6. При большой нагрузке — временно выключить приём заказов, а не «терять» заказы без ответа.
7. Вечером при необходимости выключить приём заказов.

## 14. Частые вопросы

**Изменения не видны на сайте**  
Нажали ли **«Сохранить»**? Обновите страницу сайта (Ctrl+F5). Для самовывоза / пользователей / заказов сохранение идёт своими кнопками.

**Гость не может заказать доставку по адресу**  
Адрес вне зоны доставки, или приём заказов выключен, или в корзине блюда без флага «Показывать в доставке».

**Блюдо видно в меню, но не в доставке**  
В карточке блюда включите **«Показывать в доставке»** и сохраните.

**Написали «Закончилось»**  
Выключен переключатель **«В наличии»**.

**Не сканируется QR**  
Проверьте статус заказа (должен быть «Готов» / «В пути»), свет, фокус камеры; либо введите код вручную. Нужен современный браузер (Chrome / Safari) и доступ к камере.

**Забыли пароль админки**  
Пароль меняет технический специалист на сервере (переменная окружения). Клиентам сайт сам пароль не высылает.

**Можно ли править сайт с телефона?**  
Да, панель адаптивна. Для сканера QR удобнее телефон или планшет камерой.

## 15. Чего в админке делать не нужно

- Не удаляйте «на пробу» все категории меню — восстановить вручную долго.
- Не отключайте зону доставки и точки самовывоза одновременно без предупреждения гостей.
- Не передавайте пароль админки курьерам — для них есть роль **курьер** и свой вход.
- Не храните пароль в открытых чатах с посторонними.
